How the Action attribute works

... in my own words

The action attribute on a form tag tells the browser where to send the form's data when the user submits it. Its value is a URL, usually a page or script on the server that will receive and process the information.

For example, with <form action="/signup">, clicking the submit button sends everything the user typed in the form to the /signup address. If the action attribute is left out, the browser sends the data back to the same page the form is on.
